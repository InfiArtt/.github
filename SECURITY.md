# Security Policy for InfiArtt Organization

## 🛡️ Reporting a Vulnerability

We take the security of all projects under the **InfiArtt** organization seriously. If you discover a security vulnerability in any of our open-source software (such as Accessify Play or future projects), please help us by reporting it responsibly and privately.

**Please do NOT post security issues in the public GitHub Issues tracker.**

Instead, please send an email directly to the maintainer at:
**info@infiartt.com**

### Information to Include in Your Report

To help us resolve the issue quickly, please include the following details:

* **Project Affected:** (e.g., Accessify Play, Project X)
* **Vulnerability Description:** A clear description of the security flaw.
* **Steps to Reproduce:** The exact steps needed to observe the issue.
* **Version(s) Affected:** The specific version number or commit hash of the affected project.

We commit to responding to your report within 48 hours and will work with you to resolve the issue promptly and confidentially.
